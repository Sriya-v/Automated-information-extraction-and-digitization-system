# Automated Information Extraction and Digitization System

An AI-based system designed to convert handwritten and scanned academic documents into structured digital formats.

## Features
- Document image preprocessing
- Noise removal and image enhancement
- OCR-based text extraction
- Information extraction from documents
- Generates structured JSON and Excel outputs

## Technologies Used
- Python
- OpenCV
- Pytesseract OCR
- Pandas
- OpenPyXL

## Working
1. Upload scanned document/image
2. Apply image preprocessing techniques
3. Extract text using OCR
4. Convert extracted information into structured format
5. Generate digital output files

## Output Formats
- JSON
- Excel

## Project Purpose
This project reduces manual data entry by automatically extracting information from handwritten and scanned academic documents and converting them into digital formats.
